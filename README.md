Entry for the [make.fun bounty "The Printer Finally Answers"](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907).

`main.py` (Python 3.13, standard library only, no network) writes one line —
the office printer's own comeback to the people who jam it, thump it and
stare at its cryptic error codes — to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` if set). The program is deterministic:
every run writes the exact same bytes.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
